## 同样的钱，差在哪四个地方

**线路。** 有商家在同一个洛杉矶机房放了两款 1 核 1G：普通国际线路月付 29 元，CN2 GIA 月付 87 元，差 58 元。这 58 元买的是三网回程都走优化线路、晚高峰不掉速。洛杉矶到国内的物理距离摆在那，150ms 上下就是优秀线。第三方对 CN2 GIA 线路的实测是全国三网平均 166ms 左右（电信约 157ms、联通约 160ms、移动约 182ms），本地基本无丢包；优质 BGP 三网直连的自测数据在 150～180ms。WePC 美国线写的 4837 和 9929 属于优化线路这一档，页面没给延迟实测值，别拿别家的数字往它头上套。

**CPU 平台和存储。** AMD EPYC 7002 系列正在替换老的 Intel E5v4，有商家公开称自家 AMD 7002 整机性能比 E5v4 强 50%～100%。NVMe 比 SATA SSD 快一个量级，跑数据库、高 IO 应用优先选 NVMe。WePC 美国和香港线全是 NVMe，建站线是 SSD，页面上没写具体 CPU 型号，需要确认就直接问。

**流量计费还是带宽计费。** 这是新手最容易买错的一处。流量计费给的是大端口加月流量上限，比如 200Mbps 配 1.5TB，用超了限速，次月 1 日重置，流量双向统计；带宽计费给的是小端口（5Mbps、10Mbps）但不限流量，适合 24 小时推流、大文件分发。关键差别在“超量之后限到多少”：行业里常见做法是限到 1Mbps，那个速度基本只够 SSH。WePC 美国线限 3Mbps、香港线限 5Mbps，同样是超量，体验差好几倍，这一条在别家的对比表里基本看不到。

**付款周期。** 月付单价高但灵活，年付平均到每月便宜，赶上折扣码差价能到八折。顺序是先月付试一两个月，体感对了再转年付。WePC 页面上展示的是月付起价，年付方案和折扣没公开列出来，只能进结算页看。

## 真实总成本：首月价不等于长期价

低价 VPS 的常见结构是首年给折扣、续费回原价，也有部分特价套餐是续费同价、不需要优惠码。这两种在账单上的差别，第二年才显出来。看到“首年 X 元”先翻到续费条款，确认第二年扣多少，再决定要不要一次付一年。

## 下单前要确认的六件事

1. **IP 是不是原生、是不是双 ISP。** WePC 美国线写的是全场双 ISP IP，做 TikTok、流媒体、注册类业务的人在乎这个。原生 IP 和机房广播段是两回事，敏感业务先月付验证再决定。
2. **超流量之后限到多少。** 3Mbps、5Mbps 和 1Mbps 是三种完全不同的命运。WePC 的数值写在产品页上，属于比较透明的。
3. **退款窗口多长、什么条件。** 3 天、7 天、30 天都有商家在用，还有“流量不超 10G”这类附加条件。WePC 明确写出的是建站线的 30 天。
4. **流量是不是双向统计。** 绝大多数商家按上行加下行合计，1.5TB 实际能用的比你想的少一半。
5. **用途限制。** WePC 美国线页面写得很直白：严禁使用 shadowsocks 协议，搭建要按它给的教程走。拿它做违规用途，账号和机器都可能没了，这条比价格重要。
6. **邮件和 25 端口。** WePC 有专门的邮箱用途方案，但 25 端口是否默认开放、要不要保证金，页面没写。行业里有商家要收 150 元保证金才开 25 端口，取消服务器时退回。有发信需求的，下单前直接问。

## 常见问题

**VPS 多少钱能入门？** 月付 15～30 元就能拿到 1 核 1G 的机器，年付特价摊平后更低。这个价位够练手、跑脚本、挂个小站，别指望它扛并发。

**月付还是年付划算？** 年付平均到每月更便宜，但前提是你已经确认这台机器合适。顺序是月付试错、年付省钱，反过来做就是给自己找麻烦。

**流量用完了会怎样？** 流量计费的套餐会限速到某个值，然后继续不限量用到次月 1 日重置。限速值是 1Mbps 还是 3Mbps、5Mbps，买之前必须看清。

**便宜的和贵的差在哪？** 主要差在回程线路、CPU 平台、存储类型和超量后的限速。配置表上 CPU 内存写得明明白白，线路和限速才是价格拉开差距的地方。

**美国 VPS 需要备案吗？** 不需要 ICP 备案，也不强制实名，但注册资料要真实，别用匿名网络下单，否则账号可能被标风险。

**能拿来搭代理吗？** 看商家条款。WePC 美国线明令禁止 shadowsocks 协议，这类限制在下单前就该看清，别等封号了再回头找条款。
